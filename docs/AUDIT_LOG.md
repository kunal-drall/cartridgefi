### 4.1 Hardening pass — 2026-11-27 (M2, H4, L1, adversarial C1 test)

- **Scope of limits.** Rate-limit counters and the spend ledger are in-memory and per serverless instance (pinned to `globalThis`, so all routes in one process share them). The effective ceiling is limit × live instances, and counters reset on cold start. A fleet-wide guarantee needs a shared store (Vercel KV / Upstash) or Vercel Firewall rate-limit rules. The on-chain balance floor (0.03 SOL) is still the global backstop.
- **Adversarial forged-event test (`scripts/test-forged-events.ts`).** Run 2026-11-27 13:55–14:01 UTC against the dev server on the live Devnet deployment, room `BLITZ_3M-PAPER-7981279`, RoomShard `7Sx7afpLyt2mbofMQfJPf11h41z4nr6AHF3qXi6itbjD`.
